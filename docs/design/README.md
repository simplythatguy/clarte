# Design record

The UI v0 design documents, moved here from `prototypes/UI/v0` when the prototypes left the repository
(2026-11-09). The app in `app/` still follows them; `app/DESIGN.md` records where it has moved on since.

- [`QUADRANTS.md`](QUADRANTS.md): the backend quadrant contract (Q1 to Q8), letter groups and the conversation flow. It was UI v0's README.
- [`BRIEF.md`](BRIEF.md): the brief the UI styles were built from, with its non-negotiables and quality gates.
- [`MOTION.md`](MOTION.md): motion tokens and the craft bar.
- [`SOUND.md`](SOUND.md): the sound system's rules and cue map.
- [`RESEARCH.md`](RESEARCH.md): the research synthesis behind the brief.

Paths inside these files that name `prototypes/`, `s0` to `s8`, `s_all` or `shared/` point at the prototypes as they
were. They are in git history up to commit `d6a27ca`; `shared/` became `app/src/core/`.
