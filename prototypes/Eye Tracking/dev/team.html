Team model training

Development only. Trains one shared starting model from everyone's replay recordings, in this tab, with the shipped model. Nothing is uploaded.

  1. Each person records a session in the app (Settings → Record replay set (dev), calibrate, run the full free-flow check, Save replay set). Two sessions each is better than one.
  2. Load all the files here and put the right name next to each file. Files with the same name count as the same person.
  3. Press Train. Each setting is tested by training without one person and checking that person, for every person.
  4. If it helps, download team-estimator.json and put it at public/team/team-estimator.json.
